## 2. Contamination handling (DAT-04)

The phrase-bank pools are **shared** between this mixture and the frozen eval sets, so a
different seed is not enough: **41.31% of raw records collide** with a frozen row (measured,
2026-10-03). The spec sanctions the fix explicitly (AC2: *"the records be removed and the audit
re-run — never proceed silently"*):

1. **Dedup** every raw record whose **state text** or **prompt fingerprint**
   (`sha256(state ‖ instructions ‖ criteria)`) matches any frozen record — 35,320 dropped.
2. **Re-audit** the clean set — result **`pass`**, overlap **0** on both audited sides:

| Audited side | state texts | prompt fingerprints |
| --- | ---: | ---: |
| clean mixture (50,180) | **0** | **0** |
| temperature-fit `val` (5,005) | **0** | **0** |

* **Frozen sources:** `eval_en` 1,500 · `eval_multi` 1,500 · `eval_en_domains` 7,500 · `eval_multi_domains` 7,500 = **18,000 records**.
* **Empty states** carry no information and are counted, never matched: 4,500 in the mixture, 972 in the frozen sets.
* **English cells drop ≈ 2× the others** (`en` cells lose ~1.9k records each vs ~850) because two of the four frozen sets are English — reported per cell in `artifacts/slm-mixture-v1/split_render.json`.
* **Public probes** (`typed-decisions`, `MASSIVE`, `XNLI`) are **`skipped — absent locally`**. Structural argument recorded instead of a silent pass: the generator's only inputs are the phrase banks in code plus `training/data/domains/*.json`; no external dataset import path exists.

## 3. Deterministic split (DAT-03)

`val` **iff** `int(sha256(raw_line)[:8], 16) % 10 == 0` — a pure function of the record's bytes,
so membership is stable across runs and independent of record order, of ids (positional and
colliding across domains) and of the language/domain cycles.

| Split | Records | Share |
| --- | ---: | ---: |
| `train` | 45,175 | 90.03% |
| `val` (temperature fit, Phase 4) | 5,005 | 9.97% |

## 4. SFT rendering (DAT-05 / DAT-06)

| Primitive | Prompt suffix | Target (scoring mode, PRD §3.4) |
| --- | --- | --- |
| `choice` | wire request JSON + `\nAnswer:` | the criteria **key** named by the state |
| `score` | same | the level **index** as a string (`"0"`…`"n-1"`) |
| `noul` | same | `"true"` / `"false"` (logprob gap → `sigmoid(ℓ(true)−ℓ(false))`) |

* Prompt = the frozen §5.1 request (`state` + `model` + `questions.q`); it is **parsed back with
  `tachyone.wire.parse_request`** at generation time — the same authority the contract suite uses.
* Target must be a member of the question's own candidate set; anything else is dropped and counted.
* **Result: 50,180 pairs written, 0 rejected.** Clean counts by primitive: `choice` 19,131 ·
  `score` 17,442 · `noul` 13,607 (the imbalance is dedup, not generation — `noul` states are the
  most templated, hence the most collisions; Phase 2 gates on the worst cell, §3.2).

## 7. Files & reproduction

Datasets live in `data/` (**gitignored**, ≈130 MB — regenerable in ~4 s); the small evidence
lives in `artifacts/slm-mixture-v1/` (versioned):

```bash
export TACHYONE_REPO=/path/to/munod/tachyone     # provides training.generate_data + tachyone.wire
cd <workspace>

PYTHONPATH="$TACHYONE_REPO" uv run --project "$TACHYONE_REPO" python -m slm_pipeline.generate_mixture
PYTHONPATH="$TACHYONE_REPO" uv run --project "$TACHYONE_REPO" \
    python -m slm_pipeline.prepare_sft --frozen-dir "$TACHYONE_REPO/data"
PYTHONPATH="$TACHYONE_REPO" uv run --project "$TACHYONE_REPO" pytest tests/ -q
```

## 8. Caveats (read before quoting numbers)

* **Frozen eval is now out-of-sample for this mixture** (overlap 0), which is exactly what the
  in-sample lesson L-005 demanded — but the *template structure* is shared by construction: the
  same generator and phrase banks produce both. Expect easier generalization within the same
  templating than to real traffic; the public probes remain the external check (Phase 5).
* **`noul` is the thinnest primitive** after dedup (13,607) — worst-cell gating (§3.2) should
  watch it in Phase 2.
* **Published.** Dataset live at **[`huggingface.co/datasets/munod/tachyone_slm_mixture_v1`](https://huggingface.co/datasets/munod/tachyone_slm_mixture_v1)** (Apache-2.0, public, 62.6 MB: `records/`, `pairs/`, `provenance/`, card + LICENSE) — uploaded **2026-10-04**, verified end-to-end with `load_dataset` (45,175 / 5,005 on both configs). The **model** repo [`munod/tachyone_slm`](https://huggingface.co/munod/tachyone_slm) stays reserved for the SLM weights (Phase 3/5). The pre-dedup `*.raw.jsonl` is deliberately **not** published.
* Consumed later by `docs/model-card.md` (Phase 5) — update **as a set** (AD-009).
