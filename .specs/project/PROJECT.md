# TachyOne SLM

**Vision:** Deliver the official **local System-2** of the TachyOne System-1/System-2 hybrid — a Qwen2.5-0.5B-Instruct SLM fine-tuned with SFT via LoRA, invoked by the B-3 confidence handoff (`assess_response(τ)` → `system_two()`), producing wire-valid, calibrated answers with **p50 < 20 ms** in-engine.

**For:** maintainers and users of the `munod/tachyone` hybrid classifier who need a fast, calibrated, contract-guaranteed fallback for inputs where the encoder (System-1) abstains.

**Solves:** the System-2 slot exists but is empty (user-supplied stub in `cookbook-handoff.md`), and the current LLM candidates (`ornith-9b`, `ling-tiny`) take **1.2–6.8 s p50**, violate the contract (`JSON ok` ≤ 0.889) and burn **4.8–5.5 GB VRAM** (PRD §1.3).

**Source of truth:** `docs/tachyone_prd.md` — PRD **v1.1.0** (status: in review until Phase 0 fixes the numeric accuracy targets).

**Workspace role:** specification & documentation only — **no product code** is produced here. Code lives in `munod/tachyone`.

---

## Goals (measurable, from PRD §2 / §7)

- [ ] **G1 — Latency:** p50 **< 20 ms** (stretch < 8 ms only with §4 preconditions) and p95 **< 50 ms** in-engine, GPU declared — §7.3.
- [ ] **G2 — Speed:** **≥ 50×** `ornith-9b` p50 in the same harness; throughput **≥ 20 items/s** (batch=1) — §7.3, §7.5.
- [ ] **G3 — Contract & coverage:** `JSON ok` = **1.000** on both `compare.py` sets; **100%** of abstained items get a wire-valid answer (max 1 retry) — §7.1, §7.2.
- [ ] **G4 — Accuracy:** slice accuracy (τ = 0.6 reference) **≥ LLM candidate** *and* **≥ System-1** on the same slice — exact target **fixed in Phase 0**; composite accuracy (System-1 + handoff) **≥ System-1-only** — §7.2.
- [ ] **G5 — Calibration:** ECE (10-bin, temperature fitted per primitive × language) **≤ 0.030**, with **Brier and `Conf` published alongside** — §7.4.
- [ ] **G6 — Resources:** additional VRAM **≤ 1.6 GB** (bf16) / **≤ 1.0 GB** (INT4/FP8), measured in the harness — §7.5.
- [ ] **G7 — Process:** ADR-0017 published; daily gates green; doc surfaces (`CHANGELOG`, `cookbook-handoff`, `model-card`, `benchmarks/report.md`) updated **as a set** — §7.6.

## Scope

**v1 includes (Phases 0–5):**

1. Baseline of the abstained slice + numeric accuracy targets fixed in PRD §2 (Phase 0).
2. `Tachyone-SLM-Mixture-v1` (~50k records) generated by the existing pipeline with label derivation and contamination audit (Phase 1).
3. LoRA/SFT fine-tune with experiment discipline (Phase 2).
4. LoRA merge, export (vLLM/TRT-LLM), quantization matrix INT4@3060 / FP8@L4, VRAM measurement (Phase 3).
5. Official `system_two()` implementation: scoring decoding, calibration fit, τ/retry/fallback policy — wire untouched (Phase 4).
6. Engine row in `compare.py`, KPI measurement, English publication doc set (Phase 5).

**Explicitly out of scope (PRD §1.4):**

| Item | Reason |
| --- | --- |
| Changing the `/v1/systemone` wire | Frozen by ADR-0001; `tests/test_contract_wire.py` stays green unchanged |
| Touching/retraining the System-1 encoder | Encoder is out of this epic |
| JevBench submission with the SLM | Submission remains an encoder artifact; composition System-1+2 is future work |
| Models ≥ 1B, MoE adapters | PRD non-goal |
| Multi-tenant / cloud serving | Local-first project |

## Constraints

- **Timeline:** 10 working days across Phases 0–5 (PRD §6).
- **Hardware matrix (§4):** train on RTX 3060 12 GB (bf16) or NVIDIA L4 23 GB; main serving path = RTX 3060 (Ampere, **no FP8**) with bf16 or INT4 (AWQ/GPTQ); stretch < 8 ms only with FP8 on NVIDIA L4 (Ada).
- **Wire contract:** request/response JSON frozen (`docs/protocol.md`, ADR-0001) — `answers`, `probabilities`, `confidence`, `noul`, `legend`, `usage`.
- **Experiment discipline (§3.2):** pinned seed (AD-009); verify config before running (L-011); control before blaming variance (L-006); gate on the **worst** domain/language, never the average; never gate on a *routed* harness (L-013).
- **Eval sets are frozen:** `eval_en`, `eval_multi`, `eval_en_domains`, `eval_multi_domains`, public probes never enter training prompts nor the temperature-fit validation split (§3.3).
- **Language:** new docs and PRs in **English** (PRD §6); the PRD itself remains in Portuguese (DEC-004).
- **This workspace:** no `git init`, no commits, no training/benchmark runs, no code — unless explicitly requested later.
